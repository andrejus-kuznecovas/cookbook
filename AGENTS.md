# Cookbook

A Django meal planner for two people: store recipes with ingredients, pick
meals for the coming days, and get one aggregated shopping list where shared
ingredients stack. See `README.md` for how to run it.

## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the repo root plus `docs/adr/`. See `docs/agents/domain.md`.
